Privacy Policy

Effective date: October 15, 2026

Avto Uploader ("the app") is a private desktop tool operated by Azamat Muratov for publishing his own videos to his own YouTube channel. This policy explains what data the app accesses and how it is handled.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service. Google's handling of your data is governed by the Google Privacy Policy (http://www.google.com/policies/privacy).

What data the app accesses

  • An OAuth 2.0 access and refresh token for the signed-in Google account, granted by the user on Google's consent screen.
  • Information about the user's own YouTube channel: channel ID, title, upload status and feature eligibility, the user's own videos and playlists.
  • YouTube Analytics reports for the user's own channel (views, watch time, impressions, click-through rate) and public statistics of public YouTube videos returned by search.

How the data is used

  • To upload the user's own video files, titles, descriptions, tags and thumbnails to the user's own channel and add them to the user's playlists.
  • To show the user the status of uploads and the performance of the channel, so that the user can plan future videos.

The app does not sell, rent, or share any data with third parties, does not use the data for advertising, and does not combine it with data from other sources about other people.

Storage

All data is stored only on the user's own computer: the OAuth token in a local file readable only by the user's operating-system account, and upload records next to the video files. The app has no server and does not send data anywhere other than to Google/YouTube APIs. The app does not use cookies or similar technologies on the user's device beyond the local token file.

Retention and deletion

Data stays on the user's computer until the user deletes it. API data that is cached locally is refreshed or deleted within 30 days. Deleting the token file or revoking access removes the app's ability to access the account.

Revoking access

You can revoke the app's access to your Google account at any time on the Google security settings page: https://security.google.com/settings/security/permissions.
